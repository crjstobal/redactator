How it works

Three open models read every line, and their results are merged, so a miss by one is caught by another.

  1. Drop and tick

    Add as many files as you like and tick what to hide. Type anything only you know, like your car's plate.

  2. Three detectors read it

    Fixed patterns for emails, cards and IBANs. GLiNER2-PII for names and IDs. Gemma 4 for anything that needs judgement.

  3. Review and export

    Untick what should stay visible, draw extra boxes by hand, and export clean copies. Originals are never touched.

Private by design

  • Nothing leaves your computer. The models run locally, so the file you want to clean is never sent to anyone.
  • Real PDF redaction. The text under each box is deleted from the file, not just covered with a shape.
  • Solid boxes, never blur. Blur and pixelation can be reversed. Black can't.
  • Metadata stripped. GPS, camera details and document authors are removed on export.
  • Works offline. On a train, on a plane, or inside a client's locked-down network.
  • Open source. Read every line of the code that touches your files.
